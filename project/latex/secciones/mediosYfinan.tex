\section{Medios y financiación}
Para ejecutar las tareas requeridas, el doctorando tiene accesos a la infraestructura tecnológica avanzadas integradas en su entorno profesional que es necesaria para el proceso del Big data y la simulación se cuenta con recursos de computación en la nube de Amazon Web Services (AWS), específicamente AWS ECS, S3 y RDS. Estos medios serán suficientes para implementar y probar los modelos predictivos propuestos para mejorar la eficiencia energética sin incurrir en costes añadidos para la adquisición de equipos físicos. 
La financiación se apoya en recursos propios y el doctoran se encuentra como Senior Analyst en proyectos estratégicos (Generalitat CTTI, Vodafone y Inditex). Desde su posición tiene garantía de una dedicación estable al proyecto de investigación y soportes logísticos para la validación requerida, sin necesidad de financiación externa.
